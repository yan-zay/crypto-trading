# 模拟交易引擎

> 本文档描述模拟交易引擎的设计。

## 设计理念

模拟交易使用实时市场数据和虚拟资金验证策略，与回测共享同一套组件。

## 与回测的区别

| 特性 | 回测 | 模拟交易 |
|------|------|---------|
| 数据源 | 历史文件 | 实时 WebSocket |
| 执行模式 | 同步 | 异步 |
| 资金 | 虚拟 | 虚拟 |
| 策略接口 | 相同 | 相同 |

## 使用方式

```java
paperTradingEngine.start(BigDecimal.valueOf(10000));
// ... 实时数据流入，策略自动执行 ...
paperTradingEngine.stop();
```

## 不能做的事

- 不支持真实交易
- 不支持多账户
- 不支持手动下单
