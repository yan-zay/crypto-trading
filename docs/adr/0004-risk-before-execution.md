# ADR-0004: 风控必须在执行之前

## 状态

已接受

## 背景

策略产生信号后，是否需要经过风控检查才能执行？

## 决策

**所有交易信号在执行前必须通过风控检查。**

流程：SignalEvent → RiskEngine → ExecutionEngine → VirtualAccount

## 原因

1. **安全优先**：宁可错过交易，不可超限亏损
2. **规则统一**：回测和实盘使用同一套风控规则
3. **可扩展**：添加新规则不影响执行逻辑

## 影响

### 正面

- 防止单笔大额亏损
- 防止每日累计亏损超限
- 防止持仓过于集中

### 负面

- 可能错过一些高置信度但大仓位的交易
- 风控规则过于严格时回测可能无交易
